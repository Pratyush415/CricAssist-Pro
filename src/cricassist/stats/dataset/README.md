# Dataset metadata

Describes "The Ultimate Ball-by-Ball Cricket Dataset" (built from Cricsheet,
licensed under the Open Data Commons Attribution License 1.0).

- `schema.json`: columns, types, keys and joins for each CSV.
- `manifest.json`: Cricsheet snapshot the dataset was built from, with a
  SHA-256 checksum per CSV file.

The CSV files themselves are not committed. Unzip them into `data/raw/`.
